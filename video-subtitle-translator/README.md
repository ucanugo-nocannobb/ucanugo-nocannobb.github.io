# 🎬 影片字幕即時翻譯（Chrome / Edge 擴充功能）

看影片時，把影片原本的字幕即時翻譯成你選的語言，以雙語字幕疊在影片上。

## 安裝（約 1 分鐘）

1. 下載這個 `video-subtitle-translator` 資料夾到電腦
2. Chrome 網址列輸入 `chrome://extensions`（Edge 用 `edge://extensions`）
3. 右上角打開「開發人員模式」
4. 按「載入未封裝項目」，選擇 `video-subtitle-translator` 資料夾
5. 把工具列上的 🧩 裡的「影片字幕即時翻譯」釘選起來

## 使用

1. 打開影片，**在播放器裡開啟字幕（CC）**
2. 翻譯後的字幕會自動出現在畫面下方（黃字為譯文）
3. 點擴充功能圖示可以設定：啟用／關閉、目標語言、雙語或只顯示譯文、字級

## 支援範圍

| 網站 | 說明 |
|---|---|
| YouTube | 包含自動產生的字幕 |
| Netflix | |
| Bilibili | |
| 其他網站的 HTML5 影片 | 影片需要自帶字幕軌（`<track>`） |

網站改版時，字幕位置可能變動，需要更新 `content.js` 裡的 `SITES` 設定。

## 限制

- **影片本身要有字幕**。沒有字幕的影片需要語音辨識，這個擴充功能不處理；可以改用 Chrome 內建的「即時字幕」（設定 → 無障礙 → 即時字幕），把聲音轉成字幕。
- 翻譯使用 Google 翻譯的免費公開端點，可能偶爾被限流。
- 影片以瀏覽器原生全螢幕播放（不是網站自己的全螢幕按鈕）時，疊加字幕可能看不到。
